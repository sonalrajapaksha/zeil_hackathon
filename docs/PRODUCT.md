# Product truth — Access

**Promise:** The application adapts to the candidate, rather than forcing the candidate through inaccessible forms.

Audience: jobseekers who face access barriers with conventional application forms, including people using screen readers, keyboards, voice input or simplified reading experiences. Avoid assuming disability type or inferring disability from behaviour.

Core job-to-be-done: describe experience conversationally; review extracted claims; select job; create accessible editable CV and cover letter; export with control.

Key experience: left-side conversation + right-side growing 'Living Career Canvas'. Newly extracted claims must be tentative until confirmed. No false claims or credentials.

North-star demo: a fictional candidate describes library volunteering; the system asks a helpful follow-up; their skills appear in an editable preview; they choose a customer support role, review generated materials, download them. No actual application submission.

Success: interviewers can operate it by keyboard; candidate controls disclosed information; whole flow completed in <3-minute demo after setup.
